Bridging the stack from digital logic and microcontroller registers up to distributed enterprise backends:

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  DISTRIBUTED BACKEND   │  Java 21 · Spring Boot 3 · PostgreSQL · Docker REST │
├────────────────────────┼─────────────────────────────────────────────────────┤
│  NATIVE & SYSTEM       │  C / C++ · Linux POSIX API · Android NDK / JNI      │
├────────────────────────┼─────────────────────────────────────────────────────┤
│  EMBEDDED & HARDWARE   │  STM32 (ARM Cortex) · ESP8266 · SystemVerilog · TUI │
└──────────────────────────────────────────────────────────────────────────────┘
```

* **Core Focus:** Building reliable, concurrent, and high-performance software across both bare-metal hardware and scalable cloud environments.
* **Engineering Philosophy:** Writing predictable code with comprehensive test suites, clear separation of concerns, and deep understanding of the underlying system primitives.
* **Education:** ITMO University, Faculty of Software Engineering and Computer Systems (Saint Petersburg, Russia).
